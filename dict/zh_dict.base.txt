# ---- 进程描述列 (FileDescription) ----
# 重要前提（日志实测，别想当然）：中文 Windows 上，exe 自带的 FileDescription
# 已经是微软本地化好的中文 —— "Windows 会话管理器" / "Windows 资源管理器" /
# "控制台窗口主机" / "服务和控制器应用" / "设置" 这些在我们钩子里是 [miss]，
# 但它们本来就是中文，与词典无关。
# 所以这里只收「在本系统上确实显示为英文」的两类：
#   ① System Informer 对伪进程的硬编码串（System Idle / Interrupts / Registry）
#   ② 只带英文版本资源的应用程序
# 刻意不收：第三方软件名与品牌（IDM、Catsxp Browser、TortoiseGit、TIM…）；
#           进程名/驱动名/服务名（smss.exe、AMD PCI…）—— 保留英文更利于排查。
